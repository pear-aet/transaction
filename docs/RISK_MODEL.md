# 风险模型

开仓数量取以下约束的最小值：

1. `账户权益 × 单笔风险 ÷ 每单位止损及预计成本`。
2. 单币风险剩余额度。
3. 全组合未平仓风险剩余额度。
4. 同方向名义敞口剩余额度。
5. 币种风险档位最大杠杆。
6. 配置的100倍硬上限。
7. 维持保证金、强平费和强平缓冲反推的杠杆上限。

全仓检查使用整个账户权益与所有持仓维持保证金总额。如果某币种标记价格的当根不利极值使账户权益不再覆盖总维持保证金和预计强平费，引擎保守地关闭全部仓位并触发全局停止。

限制：K线只能提供区间极值，不能恢复真实逐笔路径。超过10倍且执行周期粗于1分钟时，引擎会发出可信度警告。高杠杆研究应改用1分钟或更细数据。
