# 策略研究协议

每个币种独立运行，不能把 BTC 的胜出策略直接套给其他币种。

数据按时间分为开发区和最终测试区。最后20%历史完全隔离；开发区使用扩展式训练窗口和紧随其后的验证窗口。候选资格要求：

- 每个折叠训练成功且训练回撤不超过50%；
- 所有验证折叠均可运行；
- 验证总交易次数达到门槛；
- 最坏验证回撤不超过门槛；
- 分数同时惩罚回撤和跨窗口收益离散度。

只对验证排名第一且合格的候选运行一次最终测试。最终测试不参与重新选参。随后运行双倍手续费/滑点压力和固定种子的500次交易顺序蒙特卡洛。

外部策略不能被自动下载后直接运行。进入注册表前必须记录来源、许可证、版本、参数范围，并人工检查未来函数、递归指标偏差和隐藏的数据依赖。
