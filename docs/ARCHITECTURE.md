# 系统架构

数据适配器把合约K线、标记价格、资金费率和币种规则写入 SQLite。回测与模拟盘均从相同领域对象进入 `EventEngine`。策略只产生带止损的意图；账户层拥有最终否决权。

处理顺序：

1. 读取下一根已闭合小周期K线。
2. 执行上一根收盘后产生的待处理信号。
3. 用标记价格做全仓维持保证金检查。
4. 用合约K线按止损优先规则检查退出。
5. 应用该时间点资金费率。
6. 更新账户权益、日亏、回撤和连续亏损状态。
7. 只暴露在当前小周期收盘时已经闭合的大周期K线。
8. 生成下一根开盘才允许执行的新信号。

多币种组合回测先把所有币种K线合并为全局时间序列，然后按 `(timestamp, symbol)` 稳定排序。所有仓位共享 `EngineState.cash`，因此不会重复使用本金。

`shadow.py` 只能生成 `submitted=false` 的订单意图，模块中不存在网络提交函数。真实交易必须作为未来独立安全评审项目处理。
